# Call Next Token Feature - User Documentation

## Overview

The 'Call Next Token' feature allows officers at service counters to efficiently manage queue operations by calling the next waiting customer in a first-in-first-out (FIFO) order. This feature ensures fair service distribution and provides real-time updates to maintain queue transparency.

## How Officers Use the Feature

### Prerequisites
- You must be logged in as an officer
- Your counter must be open and operational
- There must be waiting tokens in the queue

### Step-by-Step Usage

1. **Access the Counter Dashboard**
   - Navigate to your assigned counter's dashboard
   - Ensure your counter status shows as "Open"

2. **Call the Next Token**
   - Click the "Call Next" button on your dashboard
   - The system will automatically select the next waiting token in the queue

3. **Token Display**
   - The called token number will be prominently displayed on your screen
   - The token status changes to "Called"
   - The customer's wait time and token details are shown

4. **Customer Service**
   - Attend to the customer with the called token
   - Complete the service transaction

5. **Mark Token as Complete**
   - After serving the customer, mark the token as "Served"
   - Or mark as "Skipped" if the customer doesn't respond within the allotted time

### Real-Time Updates

As an officer, you'll see live updates on:
- Current waiting queue length
- Estimated wait times for remaining customers
- Daily service statistics (served/skipped counts)
- Counter status changes

### Error Handling

- **No Waiting Tokens**: If there are no customers waiting, you'll see a message indicating the queue is empty
- **Counter Closed**: You cannot call tokens when your counter is closed
- **Authorization Error**: Only authorized officers can use this feature

### Best Practices

- Always call tokens in sequence to maintain fairness
- Monitor queue status regularly
- Keep your counter open during operating hours
- Mark tokens promptly after service completion

## Troubleshooting

### Common Issues

**"No waiting tokens available"**
- Check if there are customers in the queue
- Verify your counter is assigned to the correct service center

**"Counter is closed"**
- Open your counter through the counter management interface
- Contact an administrator if you cannot open it

**Connection issues**
- Check your internet connection
- Refresh the page if real-time updates stop working
